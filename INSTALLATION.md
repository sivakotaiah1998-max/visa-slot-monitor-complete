# 🚀 Installation Guide - Visa Slot Monitor

## Quick Installation (2 Minutes)

### Step 1: Download
```bash
git clone https://github.com/sivakotaiah1998-max/visa-slot-monitor-complete.git
cd visa-slot-monitor-complete
```

### Step 2: Load in Chrome
1. Open Google Chrome
2. Type in address bar: `chrome://extensions/`
3. Toggle ON: **"Developer mode"** (top-right corner)
4. Click: **"Load unpacked"** button
5. Select the `visa-slot-monitor-complete` folder
6. ✅ Extension installed!

### Step 3: Verify Installation
- Look for 🛂 icon in Chrome toolbar
- Click it - popup should appear
- If not showing, pin the extension (puzzle icon → pin)

---

## Initial Setup (2 Minutes)

### 1. Open Visa Website
- Go to https://www.usvisascheduling.com
- Log in with your credentials
- Navigate to appointment scheduling page

### 2. Open Extension
- Click 🛂 icon in toolbar
- Settings popup appears

### 3. Configure Settings
```
☑ Monitor All Locations (CHECKED)
Visa Type: B1/B2 ▼
Start Date: [Today]
End Date: [Today + 60 days]
☑ Enable Sound Alert
☑ Enable Desktop Notification
```

### 4. Save
- All settings auto-save ✅

## ✅ Troubleshooting Installation

### Extension won't load?
```
1. Verify folder has manifest.json
2. Check all files are present
3. Try reloading: F5 on extensions page
4. Try removing and re-adding extension
```

### Can't see extension icon?
```
1. Click puzzle icon in toolbar
2. Find "Visa Slot Monitor"
3. Click pin icon
4. Should appear in toolbar now
```

### Getting errors?
```
1. Open DevTools (F12)
2. Go to Extensions tab
3. Find "Visa Slot Monitor"
4. Check error messages
5. Report issues on GitHub
```
