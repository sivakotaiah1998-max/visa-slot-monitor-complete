# ⚡ Quick Start Guide - 5 Minutes Setup

## 🚀 Install Extension (2 Minutes)

### Step 1: Download
```bash
git clone https://github.com/sivakotaiah1998-max/visa-slot-monitor-complete.git
```

### Step 2: Load in Chrome
1. Open Chrome → Type `chrome://extensions/`
2. Enable **"Developer mode"** (top right toggle)
3. Click **"Load unpacked"**
4. Select the `visa-slot-monitor-complete` folder
5. ✅ Done! Extension installed

### Step 3: Pin Extension
- Click puzzle icon in toolbar
- Pin "Visa Slot Monitor" for easy access

---

## ⚙️ Configure Extension (2 Minutes)

### Step 1: Open Visa Website
- Go to https://www.usvisascheduling.com
- Log in with your credentials
- Go to appointment scheduling page

### Step 2: Open Extension
- Click the extension icon in toolbar
- Configuration popup opens

### Step 3: Quick Setup

**Monitor All Locations:**
```
☑ Monitor All Locations (CHECK THIS)
Visa Type: B1/B2 ▼
Start Date: [Today]
End Date: [Today + 60 days]
☑ Enable Sound Alert
☑ Enable Desktop Notification
```

**Done!** Settings auto-save ✅

---

## 🎯 Check for Slots (1 Minute)

### To Check:
1. Click **"🔍 Check Available Slots (All Locations)"**
2. Wait 2-3 seconds
3. See results!

### What Happens When Slots Found:

✅ **All Locations Mode:**
```
🔊 Plays 5 BEEPS (multi-location alert)
💬 Desktop notification: "47 slots in: Hyderabad, Delhi, Mumbai"
📊 Shows each location with dates:
   - Hyderabad: 15 slots
   - Delhi: 12 slots
   - Mumbai: 10 slots
```
